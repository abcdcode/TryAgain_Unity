## 로그라이크 슈팅 게임
매 스테이지마다 나오는 적들을 쏘아 맞춰서 처치하고 최종적으로 보스를 클리어하면 되는 게임
각 스테이지는 무작위로 정해진 특정 개수의 웨이브로 구성. 각 웨이브는 스테이지 레벨에 맞는 난이도로 배치
웨이브를 클리어할때마다 일반 보상(약한 수준의 패시브,액티브 아이템)을 획득
보스를 클리어할때마다 보스 보상(강력한 수준의 패시브,액티브 아이템)을 획득하고 다음 스테이지로 이동


## 되감기

일명 '즉석 도르마무' 시스템
되감기 게이지를 소모해 게임 진행 시점을 뒤로 되돌림
발사된 탄환, 소환된 적, 플레이어 위치, 스킬 쿨타임, 무기 탄약 수 등 거의 모든 상태정보가 되돌려짐
단, 되감기 게이지는 소모된채 돌아오지 않음
되감기 한계선은 웨이브 클리어 시 갱신됨
사망시에도 몇초간 되감기로 복구 가능한 유예시간이 주어짐. 단, 이 경우 임의 수치만큼 되감기 게이지를 추가 소모
의도 - 슈팅 게임의 피지컬 요구량을 낮추기 위한 시도. 실수를 그 자리에서 즉시 만회하고 되돌려 지루한 리트라이를 할 필요없이 연속적으로 진행 가능하도록 함
사실 - 그냥 모든 옵젝들이 되감기면서 반대로 움직이면 개쩔거같아서


## 아이템

크게 패시브 아이템과 액티브 아이템으로 구분
구현상 모두 하나의 인벤토리에 들어감. 이를 타입값으로 구분
액티브 아이템은 좌하단에, 패시브 아이템은 좌상단에 표기

패시브 - 별도의 조작을 필요로 하지 않는, 소지한 것만으로 효과를 얻는 아이템.
액티브 - 사용함으로서 효과를 보는 아이템
